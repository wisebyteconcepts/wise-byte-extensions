# WiseByteExtensions.WinUI

## Overview
WiseByteExtensions.WinUI provides a set of helpers and extension methods for WinUI applications to speed up development and promote reusable best practices.

## Features
- Converters for common data types
- Controls

## Installation
### Prerequisites
- .NET 8.0 or later
- WinUI 3 SDK

### Via NuGet
```shell
dotnet add package WiseByteExtensions.WinUI
```
Or use Visual Studio’s NuGet Package Manager.

### Manual Installation
Clone the repo and add `WiseByteExtensions.WinUI` project to your solution.
